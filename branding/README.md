# Symvolia Brand Assets

## Concept: The Tessera

The logo is inspired by the ancient Greek **σύμβολον** (symbolon) — a broken pottery
token split between two parties. When the halves reunite, they prove a shared bond.

The icon depicts a **speech bubble split into two interlocking tessera shards**:
- **Left shard** (with speech tail) in Mediterranean Blue
- **Right shard** in Terracotta

Together they represent individual verified voices combining into collective expression —
the core idea behind the platform.

## Files

| File                      | Purpose                                                     |
| ------------------------- | ----------------------------------------------------------- |
| `symvolia-icon.svg`       | Icon only (scalable, square)                                |

| `favicon.svg`             | Simplified icon for browser favicon (32×32, no speech tail) |

## Typography

The wordmark uses **Georgia** (with Palatino / serif fallbacks) to evoke classical
Greek heritage while remaining widely available across systems.

## Usage Notes

- The **icon** works at any size. Use it for app icons, social media avatars, etc.
- The **favicon** omits the speech tail for clarity at small sizes (16–32px).
- The **white variant** uses full opacity for the left shard and 70% for the right,
  maintaining the two-tone feel on dark surfaces.
- The SVG wordmark relies on system fonts — convert text to outlines for final
  production assets where font availability can't be guaranteed.
